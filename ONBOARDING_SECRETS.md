# Developer Onboarding — Secret Files

These files are excluded from git (`.gitignore`) and must be shared manually via a
**secure channel** (e.g. restricted Google Drive, 1Password, encrypted zip).
Never share via email, Slack DM, or any public channel.

---

---

## Notes

- **`firebase_options.dart` and `google-services.json`** can alternatively be
  regenerated by the new developer by running:
  ```
  flutterfire configure
  ```
  ...provided they have been granted access to the Firebase project (`focusfox-cc167`).

- **`android/app/upload-keystore.jks` and `android/key.properties`** are only
  needed for release builds. Debug/dev builds work without them.

- Once files are in place, the developer should be able to run:
  ```
  flutter pub get
  flutter run
  ```
